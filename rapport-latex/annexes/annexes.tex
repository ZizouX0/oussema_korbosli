\section{Chaîne ETL et volet décisionnel}
La chaîne ETL consolide les données opérationnelles en trois étapes : l'extraction
lit les tables sources (agences, employés, clients, objectifs, pointage) ;
la transformation nettoie et agrège les indicateurs \emph{par agence} ; le
chargement produit le datamart en étoile (\texttt{dim\_agence}, \texttt{fait\_agence}).
Les vues \texttt{V\_BI\_*} exposent une couche sémantique agrégée à Power BI, tandis
que la segmentation applique un algorithme de \emph{clustering} (K-Means) sur les
indicateurs standardisés pour faire émerger les profils d'agences.
